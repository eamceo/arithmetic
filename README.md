# Счёт на ходу

Мобильный голосовой тренажёр устного счёта. Работает как статический сайт и может быть опубликован через GitHub Pages.

## Возможности

- сложение, вычитание, умножение и деление;
- десятичные дроби и проценты;
- выбор дробей до десятых, до сотых или сотых с шагом 0,05;
- три уровня сложности;
- озвучивание примеров и распознавание голосовых ответов;
- распознавание русских и английских форм чисел, включая дробные варианты;
- короткие разные сигналы для верного и неверного ответа;
- статистика текущей тренировки;
- установка на главный экран и базовая офлайн-работа (PWA).
- удержание экрана активным во время тренировки на поддерживаемых телефонах.
- четыре секунды на произнесение ответа после начала речи; незавершённый ответ не считается ошибкой.

## Локальный запуск

Страница использует service worker и Web Speech API, поэтому её нужно открывать через HTTP, а не двойным кликом по файлу.

```powershell
npx serve .
```

Затем откройте адрес, показанный в терминале.

## GitHub Pages

1. Создайте репозиторий и загрузите в него содержимое этой папки.
2. В GitHub откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Укажите ветку `main` и папку `/ (root)`.

Для голосовых ответов рекомендуется Chrome на Android или настольном компьютере. Поддержка Web Speech Recognition зависит от браузера; при её отсутствии остаётся ручной ввод.
